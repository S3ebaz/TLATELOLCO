# Las estudiantes también marcharon

Sitio escolar de Historia de México. Línea de tiempo del movimiento estudiantil de 1968, contada desde las estudiantes que participaron.

## Archivos para subir

| Archivo | Qué es |
|---------|--------|
| `index.html` | Entrada (abre la línea de tiempo) |
| `tlatelolco-68.html` | La línea de tiempo |
| `sw.js` | Service worker |
| `.gitignore` | Ignora ZIP y archivos basura |
| `README.md` | Esta guía |

## Publicar en GitHub Pages

1. Repositorio **público**.
2. Archivos en la **raíz** de `main`.
3. Settings → Pages → `main` / `(root)` → Save.
